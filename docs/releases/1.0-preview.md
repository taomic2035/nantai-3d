# Nantai 3D 1.0 Preview

对外标题为 **Nantai 3D 1.0 Preview**，Git tag 为
`v1.0.0-preview.1`，Python 包版本为 `1.0.0rc1`。

## 能看到什么

Release 附件提供一个可直接加载的 deterministic synthetic 山村：

- 25 个空间分块，含 LOD 0/1/2；
- 约 313 万个 point-preview 点；
- 建筑、植被、围墙、石灯等可替换 registry 素材；
- Studio 状态面板与 Viewer 自由观察/漫游；
- 最小 roaming graph：2 rooms、1 plan-declared portal、2 条互逆边。

它是可运行的实际预览，不是真实照片重建，也没有真实纹理贴图。可信度保持
`synthetic / preview-only`，不可据此测量或声称任意坐标均可达。

## 下载与校验

从
[GitHub Release `v1.0.0-preview.1`](https://github.com/taomic2035/nantai-3d/releases/tag/v1.0.0-preview.1)
下载：

```text
nantai-3d-1.0-preview-data.zip
nantai-3d-1.0-preview-data.zip.sha256
```

在仓库根目录校验并解压：

```powershell
$expected = (Get-Content .\nantai-3d-1.0-preview-data.zip.sha256).Split()[0]
$actual = (Get-FileHash .\nantai-3d-1.0-preview-data.zip -Algorithm SHA256).Hash.ToLower()
if ($actual -ne $expected) { throw "Preview archive SHA-256 mismatch" }
Expand-Archive .\nantai-3d-1.0-preview-data.zip -DestinationPath . -Force
```

归档只写入 `web/data/`。内部 `SHA256SUMS.txt` 可用于逐文件复核。

## 启动

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe make.py serve
```

打开 <http://127.0.0.1:8000/web/studio/>。首次加载数十 MB 数据需要等待；
Viewer 会按相机距离选择分块和 LOD。

## 真实数据仍缺什么

Preview 不关闭以下五个门：

1. 真实重叠照片或视频采集；
2. accepted real-photo SfM；
3. 非 mock GPU 3DGS 训练；
4. 实测米制对齐；
5. 真实重建产物的 Viewer QA。

真实任务的端到端步骤见
[重建环境手册](../manual/reconstruction-setup.md)。
