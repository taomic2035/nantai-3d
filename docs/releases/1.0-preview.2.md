# Nantai 3D v1.0.0-preview.2

这是当前 Preview 的唯一安装与验证入口。Git tag 为
`v1.0.0-preview.2`，Python 包版本为 `1.0.0rc2`。

## 能看到什么

`nantai-3d-v1.0.0-preview.2-runtime.zip` 是一个确定性、自包含项目内容的
runtime。解压后无需另找 Release 素材或开发机缓存即可看到：

- 默认整村 GLB：539 个 mesh、24 个视觉材质，简化 PBR；
- 67,858 个 synthetic Gaussian，以及 DC 点云 LOD 0/1/2；
- 25 个围绕原点烘焙的世界分块；
- 11/11 个内容寻址 registry 素材；
- 离线 vendored Viewer 依赖、Studio、发布 receipt 和逐文件 checksum。

包仍需 Python 3.11–3.13 和正常安装声明的 Python dependencies；它不是原生
独立应用。首次打开 Studio 会显示“Preview 只读模式”，默认 Viewer 首屏是整村
模型，而不是静默退回稀疏点阵。

## 下载的三个文件

从 GitHub Release `v1.0.0-preview.2` 下载且只使用：

```text
nantai-3d-v1.0.0-preview.2-runtime.zip
nantai-3d-v1.0.0-preview.2-runtime.zip.sha256
nantai-3d-v1.0.0-preview.2-cover.png
```

ZIP sidecar 绑定下载到的 archive bytes；包内 `RELEASE-MANIFEST.json` 和
`SHA256SUMS.txt` 再绑定解压后的 protected files。封面来自最终候选包的默认
Viewer 首屏，不是独立 Blender render。最终字节数、ZIP/封面 SHA-256 和 receipt
content ID 以该 GitHub Release 的冻结记录为准，不从候选构建猜测。

本次冻结封面由干净解压包在 1280×720 viewport 下直接截取：

```text
file: nantai-3d-v1.0.0-preview.2-cover.png
dimensions: 1280×720
byte_length: 50905
sha256: 3073d597b385c4edf1b9c2988d0a00d2811a802260ee8c78a9db72b8f7a431d0
```

## Windows PowerShell：校验、安装、运行

在三个下载文件所在目录执行：

```powershell
$archive = ".\nantai-3d-v1.0.0-preview.2-runtime.zip"
$sidecar = ".\nantai-3d-v1.0.0-preview.2-runtime.zip.sha256"
$expected = (Get-Content $sidecar).Split()[0].ToLower()
$actual = (Get-FileHash $archive -Algorithm SHA256).Hash.ToLower()
if ($actual -ne $expected) { throw "Preview2 archive SHA-256 mismatch" }

Expand-Archive $archive -DestinationPath . -Force
Set-Location .\nantai-3d-v1.0.0-preview.2

python scripts\verify_preview_release.py .
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe scripts\verify_preview_release.py .
.\.venv\Scripts\python.exe make.py serve
```

第一次 `verify_preview_release.py` 只用 Python 标准库，在安装任何依赖前检查
原始提取树；第二次确认创建 `.venv` 和 editable-install metadata 后，受保护内容
仍然完全一致。成功时打印 `Preview package verified`、`v1.0.0-preview.2`、
source commit、package content ID 和 `scene trust effect: none`。校验返回码
`2` 时不要启动或替换 receipt。

## macOS / Linux：校验、安装、运行

```bash
# macOS
shasum -a 256 -c nantai-3d-v1.0.0-preview.2-runtime.zip.sha256
# Linux 可改用：
# sha256sum -c nantai-3d-v1.0.0-preview.2-runtime.zip.sha256

unzip nantai-3d-v1.0.0-preview.2-runtime.zip
cd nantai-3d-v1.0.0-preview.2

python3 scripts/verify_preview_release.py .
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e .
.venv/bin/python scripts/verify_preview_release.py .
.venv/bin/python make.py serve
```

Studio 地址是 <http://127.0.0.1:8000/web/studio/>。命令行保持运行时再打开浏览器。

## 首次打开与交互

预期顺序：

1. Studio 显示 `Release package: verified`，并另外显示场景是
   `synthetic / preview-only / arbitrary / unaligned`；
2. Viewer 依次读取世界清单、重建证据、高斯后备、模型清单、模型 bytes，并校验
   GLB SHA-256；
3. 默认出现可辨认的整村模型三分之四视角；
4. 点 `查看高斯 / 点云` 可看 3DGS/LOD 后备，点 `查看整村模型` 返回；
5. 鼠标拖拽旋转，滚轮缩放；`W/A/S/D` 移动，`Q/E` 升降，`F` 切换自由/环绕，
   `0–3` 控制自动或固定 LOD。

模型清单、下载、SHA 或解析失败时，Viewer 会停在明确的失败阶段并显示
`重试加载`。只有用户点 `查看高斯 / 点云后备` 才进入后备；降级不会被写成模型
成功，也不会提升 provenance。

## 两类“可信”必须分开

发布 receipt 验证只证明 ZIP 中受保护的 bytes 与构建时一致：

```text
package integrity = verified
trust_effect=none
```

场景证据仍然是：

```text
synthetic=true
geometry_usability=preview-only
scale_status=arbitrary
alignment_status=unaligned
real_photo_textures=false
```

因此本版无照片纹理，不可测量，没有完成真实照片重建，也不承诺照片级真实感或
任意坐标连续可达。Batch35 不在本包内；私有 PBR bundle 不在本包内。两者即使在
开发机或其它 Release 中存在，也不能被 runtime 自动发现或提升为已发布能力。

## 损坏或加载失败

- ZIP SHA 不匹配：重新从同一个 tag 下载 ZIP 和 sidecar，不要只换其中一个。
- tree verifier 返回 `2`：该提取目录已缺文件、多文件或有 protected byte 改变；
  删除整个目录后重新解压。
- 模型失败但高斯后备可用：可明确选择后备继续预览，但这不是完整模型加载成功。
- Studio 显示 package invalid / not packaged：不要把场景证据当作已验证发布包。
