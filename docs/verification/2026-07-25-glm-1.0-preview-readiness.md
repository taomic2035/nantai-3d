## Release boundary

1.0 Preview may ship the source code and a clean synthetic Viewer dataset.
It must not ship private candidates, failed generations, temporary probes,
Blender work directories or hand-authored evidence as runtime data.

The release remains `synthetic / preview-only`. It does not close:

1. real overlapping capture;
2. accepted real-photo SfM;
3. non-mock GPU 3DGS training;
4. measured metric alignment;
5. Viewer QA over a real reconstruction.

These five gates are why the release is Preview rather than GA.
